###1. 셸 스크립트와 자동화의 필요성

- 반복적으로 사용하는 명령어를 셸 스크립트로 작성

- 스크립트를 이용한 자동화로 작업 시간을 단축하고 실수를 줄일 수 있음

- 단, 스크립트가 제대로 작성되어 있어야 자동화의 효과를 얻을 수 있음

###2. Qwen 모델과 Ollama 서버

1) Qwen

- 알리바바 클라우드에서 개발한 대규모 언어 모델(LLM)

- 텍스트 질문과 답변을 처리하는 모델을 사용

- 이번 실습에서는 답변의 지능보다는 모델의 실행, 종료, 재실행 흐름을 확인

- B는 **Billion(10억)**을 의미하며, 모델의 파라미터 수를 나타낼 때 사용

2) Ollama

- LLM을 로컬 환경에서 쉽게 설치하고 실행할 수 있도록 해주는 오픈소스 플랫폼

실행 구조

브라우저
   ↓
Python 웹 앱 (chat.py)
   ↓
Ollama 서버
   ↓
Qwen 모델

###3. 셸 스크립트 작성

코드 분석

#!/bin/bash

cd "$(dirname "$0")" || exit 1

exec python3 chat.py

#!/bin/bash

#! : 셔뱅(Shebang)

파일의 첫 줄에 작성하며, 뒤에 지정한 프로그램으로 파일을 해석하라는 의미

위 코드에서는 Bash로 이 파일을 실행하도록 지정

cd "$(dirname "$0")" || exit 1

$0 : 현재 실행한 스크립트의 이름 또는 경로

dirname : 파일 이름을 제외하고 디렉터리 경로만 출력

$(...) : 괄호 안의 명령어를 실행하고 그 결과를 사용하는 명령어 치환

"" : 경로에 공백이 포함되어 있어도 하나의 경로로 처리하기 위해 사용

|| : 앞의 명령이 실패했을 때 뒤의 명령 실행

exit : 현재 스크립트 종료

0 : 정상 종료

0이 아닌 값 : 오류 또는 비정상 종료

→ 스크립트가 위치한 디렉터리로 이동하고, 이동에 실패하면 스크립트를 종료

exec python3 chat.py

exec : 현재 실행 중인 프로세스를 다른 프로그램으로 대체

현재 Bash 프로세스를 python3 chat.py로 대체하여 실행

4. Here Document를 이용한 파일 생성

cat > start_with_export.sh << 'EOF'

입력한 내용을 start_with_export.sh 파일에 저장

EOF가 입력되면 입력 종료

주요 문법

<< : **히어독(Here Document)**을 시작

EOF : 입력 종료를 나타내는 문자열

EOF는 다른 문자열로 지정해도 되며, 시작과 끝의 문자열이 같아야 함
