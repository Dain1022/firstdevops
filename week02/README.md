## 2주차 오늘 배운 내용

### 1. 가상화

가상화는 실제 서버나 컴퓨터의 자원을 논리적으로 나누어 여러 환경에서 사용할 수 있도록 하는 기술

#### 서버
- **서버**: 다른 컴퓨터나 프로그램에 필요한 기능이나 데이터를 제공하는 주체

#### 서버 운영 방식 비교

- **베어메탈**
  - 실제 컴퓨터 하드웨어 위에 OS를 직접 설치
  - 여러 소프트웨어를 직접 실행
  - 구조 단순, 성능 우수

- **하이퍼바이저 가상화**
  - 하나의 PC에서 여러 개의 가상 머신을 실행
  - 각 가상 머신마다 OS까지 가상화
  - 격리 강함, 오버헤드 큼

- **컨테이너 가상화**
  - 하나의 PC에서 여러 개의 컨테이너를 실행
  - OS 전체가 아닌 애플리케이션 중심으로 가상화
  - 가볍고 빠르게 실행, 배표 용이
  --> 서버를 효율적으로 사용하기 위한 가상화 기술

| 베어메탈 |물리서버|프로그램->시스템콜->os커널->하드웨어|
|하이퍼바이저|VM|프로그램->시스템콜->게스트 os커널->가상 하드웨어->하이퍼바이저->하드웨어|
|컨테이너|컨테이너|프로그램->시스템콜->컨테이너 엔진->호스트 os커널->하드웨어|

하이퍼바이저 vs 컨테이너
하이퍼바이저
- 호스트 OS와 게스트 OS의 커널이 독립적으로 존재
- 각 VM이 별도의 OS를 포함하기 때문에 상대적으로 오버헤드가 큼

컨테이너
- 별도의 게스트 OS 커널 없이 호스트 OS의 커널을 사용
- 호스트 OS 커널의 기능을 이용하여 격리된 실행 환경을 만듦
- 여러 컨테이너가 하나의 호스트 OS 커널을 공유
- VM보다 가볍고 빠르게 실행할 수 있음

### 2. WSL2(Windows Subsystem for Linux)

- 빠른 실행 속도
- Windows와 Linux 시스템의 통합
- Bash 명령어를 그대로 사용할 수 있어 편리함

## 새로 배운 명령어

### WSL / Linux


| 명령어 | 설명 |
|---|---|
| `sudo` | 관리자 권한으로 명령어 실행 |
| `chmod` | 파일이나 디렉터리의 권한 변경 |
| `touch` | 새로운 파일 생성 |
| `cat` | 파일 내용 확인 |
| `cat >` | 파일을 생성하거나 내용을 덮어쓰기 |
| `cat >>` | 파일의 마지막에 내용 추가 |
