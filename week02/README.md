# 2주차

## 오늘 배운 내용

### 1. 가상화

가상화는 **실제 서버나 컴퓨터의 자원을 논리적으로 나누어 여러 환경에서 사용할 수 있도록 하는 기술**이다.

#### 서버
- **서버**: 다른 컴퓨터나 프로그램에 필요한 기능이나 데이터를 제공하는 주체

#### 가상화 방식 비교

- **베어메탈**
  - 실제 컴퓨터에 OS를 직접 설치
  - 여러 소프트웨어를 직접 실행

- **하이퍼바이저 가상화**
  - 하나의 물리적인 PC에서 여러 개의 가상 머신(VM)을 실행
  - 각 가상 머신마다 OS까지 가상화

- **컨테이너 가상화**
  - 하나의 PC에서 여러 개의 컨테이너를 실행
  - OS 전체가 아닌 애플리케이션 중심으로 가상화
  - 가상 머신보다 가볍고 빠르게 실행 가능

### 2. WSL2

**WSL2(Windows Subsystem for Linux 2)**를 사용하여 Windows에서 Linux 환경을 실행하는 방법을 배웠다.

- Linux 명령어를 Windows 환경에서 사용할 수 있음
- 빠른 실행 속도
- Windows와 Linux 시스템의 통합
- Bash 명령어를 그대로 사용할 수 있어 편리함

## 새로 배운 명령어

### WSL / Linux

| 명령어 | 설명 |
|---|---|
| `sudo` | 관리자 권한으로 명령어 실행 |
| `chmod` | 파일이나 디렉터리의 권한 변경 |
| `touch` | 새로운 파일 생성 |
| `cat` | 파일 내용 확인 |
| `cat >` | 파일을 생성하거나 내용을 덮어쓰기 |
| `cat >>` | 파일의 마지막에 내용 추가 |
