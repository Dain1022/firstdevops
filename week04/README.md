## 오늘 배운 것

### 1. 자동화

#### 1) 디렉터리와 경로, 정보 찾기

- 디렉터리와 경로를 이해하고, `find`, `grep`, 파이프(`|`)로 필요한 정보를 찾는다.
- 변수, 인자, 조건, 반복을 이용해 **셸 스크립트**를 작성한다.

```bash
# 디렉터리 100개 만들기
for i in $(seq 1 100); do mkdir -p test/dir$i; done

# 로그에서 ERROR가 포함된 줄만 찾기
cat server.log | grep ERROR
```

#### 2) ls 옵션

| 옵션 | 설명 |
|------|------|
| `-l` | 상세 보기 |
| `-d` | 디렉터리 **자체** 정보 보기 |

### 2. 프로세스와 백업

- **프로세스와 PID**를 확인한다.
- **백업 및 복원** 작업을 자동화한다.

```bash
ps aux              # 실행 중인 프로세스 목록
ps aux | grep nginx # 특정 프로세스 찾기
kill <PID>          # PID로 프로세스 종료
```

### 3. Git 협업

#### 1) 협업 흐름

- `.gitignore`로 관리하지 않을 결과물 제외
- `feat` 브랜치 생성 → 커밋/푸시 → PR → `main`에 Merge
- conflict 발생 → **로컬에서 해결** → 커밋/푸시 → PR Merge

```text
feat 브랜치 → 커밋/푸시 → PR → main Merge
                  ↑
        conflict 발생 시 로컬에서 해결 후 다시 커밋/푸시
```

#### 2) Merge 방식 비교

| 방식 | 설명 |
|------|------|
| `--merge` | 기존 커밋을 유지하고 **merge commit**을 생성 |
| `--squash` | 여러 커밋을 **하나로 합쳐서** 반영 |
| `--rebase` | feature 브랜치의 각 커밋을 **새 커밋으로 만들어** main 뒤에 일렬로 적용 |

### 4. 네트워크

#### 1) 핵심 개념

| 개념 | 설명 |
|------|------|
| **IP 주소** | 네트워크에서 장치를 식별하는 주소 |
| **포트** | 컴퓨터 안에서 실행 중인 서비스를 구분하는 번호 |
| **DNS** | 도메인 이름을 IP 주소로 변환 |

> IP가 **컴퓨터를 찾는 주소**라면, 포트는 그 컴퓨터에서 제공하는 **서비스를 구분하는 번호**이다.

#### 2) 네트워크 명령어

| 명령어 | 용도 |
|--------|------|
| `ip addr` | IP 주소 확인 |
| `ping` | 응답 확인 |
| `dig` | DNS 조회 |
| `curl` | HTTP 요청 |

#### 3) Docker와 포트 (`-p`)

```bash
docker run -p 8080:80 nginx
```

```text
-p 8080 : 80
    │      │
    │      └── 컨테이너 안의 포트 (nginx는 80번 사용)
    └───────── 호스트(내 컴퓨터)의 포트
```

- `-p` = `--publish`
- 형식: `-p 호스트포트:컨테이너포트`
 내 컴퓨터 8080호로 온 손님을 컨테이너 80호로 안내한다.

#### 4) TCP/IP 기본 구조

```text
┌─────────────────────────────────────────────┐
│ 응용 계층    HTTP, DNS, SSH                 │  ← 우리가 사용
├─────────────────────────────────────────────┤
│ 전송 계층    TCP / UDP                      │  ← 포트
├─────────────────────────────────────────────┤
│ 인터넷 계층  IP                             │  ← IP 주소
├─────────────────────────────────────────────┤
│ 링크 계층    이더넷, WiFi                   │  ← 랜선, 와이파이 등
└─────────────────────────────────────────────┘
```

#### 5) DNS (Domain Name System)

- 도메인 이름에 대응하는 **IP 주소를 찾는** 역할

```bash
dig example.com
```

#### 6) curl 옵션

| 옵션 | 설명 |
|------|------|
| `-I` | `--head`, HEAD 요청을 보내 **응답 헤더** 확인 |
| `-s` | `--silent`, 진행률 또는 불필요한 메시지 숨김 |
| `-o` | `--output`, 결과를 화면 대신 **파일로 저장** |

```bash
curl -I https://example.com                  # 응답 헤더만 확인
curl -s https://example.com                  # 진행률 없이 출력
curl -s -o page.html https://example.com     # 파일로 저장
```
